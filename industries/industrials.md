# 工业/机械行业深度研究附录

适用于通用机械、自动化、电气设备、航空航天与国防、多元工业集团、工程建筑。特征：订单前置 + 长短周期混合 + 服务后市场，估值核心在于"周期位置识别 + 质量分层"。多元集团一律用 SOTP。

## 1. 使用原则

- **先分辨周期长度**，这决定了用哪个指标做先行判断：
  - **短周期**（刀具、通用件、配电、气动液压）：跟随 PMI/工业产出，库存周期约 12–18 个月。
  - **长周期**（航空发动机、能源装备、大型项目）：看订单/backlog 与交付节奏，**收入是滞后指标**。
  - **自动化/软件化工业**（机器人、PLC、工业软件）：结构性渗透逻辑叠加周期，必须拆开讨论。
  - **国防**：预算驱动，看武器项目生命周期与固定价合同的成本超支敞口。
- **工业股的核心估值纪律是周期定位**：必须先回答"当前利润率处于 10 年带宽的哪个位置"，再谈倍数。
- **订单先于收入**。orders 和 book-to-bill 的边际变化是第一信号，收入确认往往滞后 2–6 个季度。
- 服务/后市场是工业公司的质量分层依据。装机基数带来的服务收入现金流稳定性显著高于设备销售，应在 SOTP 中单独给倍数。
- 多元集团必须 SOTP，并**显式讨论"工业味"折价与分拆催化剂**。

## 2. 信息来源与公允机制

### 来源优先级

1. **财报与订单公告**：10-K/10-Q、分部披露、订单与 backlog 明细、合同资产/负债附注。国防公司另看预算文件（美国 DoD budget request、各国国防白皮书）。
2. **宏观/中观数据**：PMI（尤其**制造业新订单分项**）、工业产出、核心资本品订单（美国 Census M3）、产能利用率。
3. **行业协会统计**：机床协会、机器人协会（IFR）、电气设备协会的出货与订单数据。
4. **竞标与项目数据库、航展订单**：长周期公司的订单来源验证。
5. **高频代理**：分销商月度数据（如 Fastenal）、渠道调研，作为短周期需求的先行代理，需交叉验证。

### 公允机制

- **Backlog 定义必须写明**：是否含意向订单、是否可取消、是否含期权批次、是否含未生效合同。**backlog 定义变更是常见的粉饰手段**。
- **订单与收入分离**：订单增长不等于收入增长，需说明转化周期和取消率。
- **POC（完工百分比）警示**：项目制公司的利润确认依赖进度估计。**利润率突升必须用现金流验证**。
- **反证优先写入**：例如"订单复苏"必须绑定 book-to-bill、渠道库存和终端客户 capex，而不是只引用管理层描述。
- **区分补库与真实需求**：短周期公司的订单反弹常常是渠道补库，需用终端消耗数据验证。
- **避免幸存者偏差**：peer set 需纳入周期低谷中的公司和已失去技术领先的同业。

## 3. 工业价值驱动树

工业公司价值可以拆成：

```text
企业价值 =
  设备/新机收入 × 周期位置调整
  + 服务/后市场收入 × 装机基数 × 附着率 × 服务利润率
  + 长周期 backlog 转化的可见收入
  × 中周期利润率
  × 资本效率（ROIC vs WACC）
  ÷ 风险折现率
  − 项目执行风险（超支、索赔、罚款）
  − 周期资本错配（高点扩产）
  − 并购商誉与整合损耗
```

报告中至少回答：

- 当前处于周期的哪个位置？利润率在 10 年带宽的哪个分位？
- 订单/backlog 的质量如何？可取消比例多大？转化为收入的周期多长？
- 服务与后市场占收入和利润的比重是多少？是否被设备业务交叉补贴？
- 项目制业务的 POC 确认与现金收取是否匹配？合同资产是否异常增长？
- 并购是否稀释了 ROIC？商誉占净资产比例如何？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 适用类型 | 常见陷阱 |
|---|---|---|---|
| Orders / 订单增速 | 新签订单 | 全类型 | **先行于收入，是第一信号** |
| Book-to-bill | 订单 / 出货 | 长周期、自动化 | 大于 1 表示 backlog 累积 |
| Backlog | 在手订单 | 长周期、项目制 | **定义可含意向；可取消部分需单列** |
| Backlog 覆盖年数 | backlog / 年收入 | 长周期、国防 | 决定收入可见度和 DCF 显性期长度 |
| 渠道库存 | 分销商库存水平 | 短周期 | **补库常被误当终端需求** |
| 产能利用率 | 实际产出 / 产能 | 全类型 | 影响经营杠杆与定价能力 |
| 装机基数 | 在役设备数量 | 有后市场业务 | 服务收入的基础 |
| 服务占比 | 服务收入 / 总收入 | 全类型 | 高服务占比应获质量溢价 |
| 服务附着率 | 服务收入 / 装机基数 | 有后市场业务 | 反映客户黏性与定价能力 |
| 续约率 | 服务合同续约比例 | 有后市场业务 | 下降是竞争加剧的早期信号 |
| POC 进度 | 完工百分比确认 | 项目制、国防 | **利润率突升需现金流验证** |
| 合同资产/负债 | 未开票收入 / 预收款 | 项目制 | **合同资产激增是红旗** |
| 索赔与争议 | 未决索赔金额 | 工程建筑 | 常在诉讼中才暴露 |
| 固定价合同占比 | 固定价 vs 成本加成 | 国防 | 固定价合同承担成本超支风险 |
| 中周期利润率 | 10 年平均经营利润率 | 全类型 | **估值锚，不用当期利润率** |
| 利润率带宽分位 | 当前利润率在 10 年区间的位置 | 全类型 | 周期定位的核心工具 |
| ROIC | 投入资本回报率 | 全类型 | 并购后需检查是否稀释 |
| 商誉 / 净资产 | 并购累积 | 多元集团 | 高商誉伴随低 ROIC 是价值毁灭信号 |
| 重组费用频次 | "一次性"费用出现频率 | 全类型 | 年年发生就不是一次性 |

必须优先披露的 8 个指标：订单与 book-to-bill、backlog 及其质量、渠道库存、服务收入占比与附着率、当前利润率在 10 年带宽的分位、合同资产变化、ROIC、商誉占比。

## 5. 财务模型结构

### 收入模型

按周期类型选择驱动：

1. **短周期**：`终端需求（PMI/工业产出代理）× 份额 × 价格`，叠加渠道库存的补库/去库调整。
2. **长周期**：`期初 backlog + 新签订单 − 交付确认 − 取消 = 期末 backlog`，收入由 backlog 按交付节奏转化。
3. **服务/后市场**：`装机基数 × 附着率 × 单台服务收入`，装机基数随新机销售累积并按退役率衰减。
4. **项目制**：按项目建 POC 曲线、合同金额、成本预算和索赔；现金收取节奏单列。
5. **国防**：按武器项目生命周期（研发→低速试产→批产→服务）建模，区分固定价与成本加成合同。

最低预测要求：

- 至少 3 年历史、8 个季度历史。
- 未来 5 年显性预测，必须显式给出周期假设（当前处于周期哪个阶段、何时见顶/见底）。
- 设备与服务收入必须分列，分别给利润率。
- 单列有机增长与并购；无法拆分时写"未获取到拆分"并降低置信度。

### 成本、利润率与资本模型

- **利润率带宽**：建立 10 年经营利润率的最高、最低、中位数带宽，标注当前位置。这是周期定位的核心工具。
- **经营杠杆**：量、价、成本传导的敏感性。短周期公司的毛利率环比变化是**量价与成本传导的即时读数**。
- **服务利润率**：必须单独披露或估算。若服务利润率被用于交叉补贴设备亏损，需还原真实设备业务盈利能力。
- **项目成本**：固定价合同的成本超支风险必须建模，尤其是首件、新技术和长期合同。
- **营运资本**：合同资产、存货、预收款的变化会显著影响现金流。**合同资产（未开票收入）持续快于收入增长是重大红旗**。
- **并购与商誉**：检查历史并购的 ROIC 贡献、商誉减值风险和整合成本。

### 稳态假设边界

- **禁止用峰值利润率做永续假设**。终值必须使用中周期利润率。
- 若订单下滑、渠道库存高企、产能利用率下降，不能同时给高增长和高利润率。
- 长周期公司的 backlog 转化率需扣除历史平均取消率，不得按 100% 转化。
- 服务收入的增长受装机基数增速约束，不能长期高于新机销售增速。

## 6. 估值方法

Scenario analysis可参考参数
### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 中周期收入增速 | | | | |
| 中周期经营利润率 | | | | |
| 服务占比路径 | | | | |
| 中枢 EV/EBITDA | | | | |
| ROIC vs WACC | | | | |
| 情景概率 | | | | |


1. **中周期盈利 × 中枢倍数**：工业股的核心纪律。**禁止峰值利润 × 峰值倍数**——这是周期股估值最常见的致命错误。用 10 年利润率带宽定位当前周期位置。
2. **EV/EBITDA 为主倍数**：工业公司资本结构差异大，EV 口径比 P/E 更可比。
3. **SOTP**：多元集团必须分部估值，服务/后市场业务单独给较高倍数。
4. **Backlog 折现**：国防/长协类公司可用 backlog 覆盖年数折算收入可见性，DCF 显性期可相应拉长。

### Peer set 规则

选择 5-10 家可比公司，并标注选择理由：

- 周期长度：短周期、长周期、项目制，不可混装。
- 服务占比：高后市场占比与纯设备销售的估值中枢差异显著。
- 终端市场：航空、能源、汽车、建筑、半导体设备的周期不同步。
- 技术含量：自动化/软件化程度决定利润率上限。
- 资本结构与并购策略：内生增长为主 vs 并购驱动。

剔除项必须说明：若某公司看似同业但周期长度或服务占比明显不同，不应强行放入同一倍数表。

## 7. 护城河与竞争判断

工业护城河的核心是**装机基数与切换成本**，不是单纯的技术。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 装机基数与后市场 | 大装机基数带来高附着率服务收入，利润率显著高于新机 | 服务占比低，或服务被第三方抢走 |
| 认证与规格锁定 | 产品写入客户规格书或行业标准，切换需重新认证 | 通用件，可直接替换 |
| 技术与专利 | 核心技术形成性能差距并体现为溢价 | 技术差距缩小，价格竞争加剧 |
| 分销网络 | 覆盖广、响应快的分销与服务网络 | 依赖第三方分销，无终端触达 |
| 规模与成本 | 规模带来采购与制造成本优势 | 规模不足或产能利用率长期偏低 |
| 客户关系深度 | 联合开发、进入客户产品路线图 | 竞标定价，无长期关系 |
| 项目执行记录 | 大型项目按预算按时交付的历史 | 频繁超支、延期和索赔 |
| 资本配置 | 并购持续提升 ROIC，无商誉减值 | 并购堆积商誉但 ROIC 稀释 |

定性护城河必须与财务证据交叉：若声称"技术领先"，但中周期利润率不高于同业、ROIC 持续下滑，必须解释矛盾。
