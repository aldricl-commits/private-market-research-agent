## 1. 使用原则

- 本附录三类标的共享同一个核心检验：**token 激励制造的"使用"是不是真需求**。链游的 play-to-earn、消费应用的积分空投、DePIN 的挖矿收益，都会制造没有 token 就不存在的虚假繁荣。研究的第一功课是把激励拿掉后看剩下什么。
- **链游**：先是游戏后是链。判断顺序：游戏好不好玩（留存数据）→ 经济系统可不可持续（产出/消耗平衡）→ token 有没有必要。顺序反了的项目（先 tokenomics 后玩法）base rate 极差。
- **消费应用**：对照 Web2 同类的留存与变现基准——crypto 不豁免消费产品规律；"链上"只有在带来真实差异（资产所有权、可组合性、抗审查）时才是卖点。
- **DePIN**：本质是**用 token 补贴换供给侧冷启动**的资本模型。核心问题永远是需求侧：供给堆起来之后，谁在付费使用？供给增长 ≠ 业务增长。
- 上一周期 base rate 必须引用：P2E 游戏、X-to-earn、存储挖矿的存活率与 token 回撤幅度，作为同模式新项目的先验。

## 2. 信息来源与核验

- **链游**：链上活跃钱包（去女巫）、NFT/道具交易量、DAU 留存 cohort（Dune）；游戏侧 Steam/Discord/直播平台数据交叉；下载量（Sensor Tower 类）与链上活跃对账——差距巨大时说明链上部分是农民。
- **消费应用**：协议收入与手续费（DefiLlama）、活跃地址留存、社交平台真实互动率；应用商店排名与评论。
- **DePIN**：供给侧节点数与地理分布（项目 dashboard，链上可验证部分标注）、**需求侧付费收入**（多数项目的死穴，重点挖）、单位供给收益（节点回本周期）。
- **快照对齐**：空投/积分活动日历与数据曲线对齐——快照前的冲量全部剔除。
- 收入口径：区分**协议收入**（用户真实付费）与 **token 排放补贴的名义 GMV**；DePIN 区分"网络烧掉的 token"与"外部客户付的法币/稳定币"。

## 3. 价值驱动树

**链游/消费**：

```text
应用价值 =
  真实用户数（去农民后的 DAU/MAU）
  × 留存质量（D30/D90 留存 vs Web2 同品类基准）
  × ARPU（付费转化 × 客单，剔除 token 投机性购买）
  × 变现留存率（收入归协议/开发商的比例）
  × 内容/网络效应持续性
  − 用户获取成本（含空投/积分的真实成本）
```

**DePIN**：

```text
网络价值 =
  需求侧付费收入（外部客户真实支付）
  × 需求增长可信度（管道/合同/使用量趋势）
  × 网络 take rate
  − 供给侧补贴净支出（token 排放价值 − 节点贡献的真实资源价值）
  × 供给侧稳定性（停止补贴后节点留存）
```

报告中至少回答：

- 剔除激励后的留存是多少？（找激励间歇期或对照组）
- （链游）经济系统产出/消耗平衡表：token/道具的水龙头与水槽，通胀压力多大？
- （消费）为什么这个产品需要链？资产所有权/可组合性带来的留存或变现差异有没有数据支持？
- （DePIN）需求侧收入现在是多少？供给侧回本周期多长，token 价格跌 50% 节点会不会关机潮？
- 获客的真实成本：空投/积分按发放时价值算进 CAC 了吗？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 真实 DAU/MAU | 去女巫后的活跃 | 用户基数 | 多号农民；任务平台刷量 |
| D7/D30/D90 留存 | cohort 留存曲线 | 产品力核心证据 | 空投预期支撑的"留存"；快照后断崖 |
| 付费转化与 ARPU | 付费用户比 × 客单 | 变现能力 | token 投机性购买混入；大 R 集中 |
| 协议/开发商收入 | 真实归属收入 | 商业模式验证 | 一级市场道具销售是预支未来 |
| 经济平衡（链游） | token/道具产出 vs 消耗 | 经济可持续性 | 只看产出端；靠新增用户接盘=庞氏结构 |
| 内容成本与更新节奏 | 版本/内容 roadmap 兑现 | 供给持续性 | 外包换皮；roadmap 跳票史 |
| 节点数与增速（DePIN） | 供给侧规模 | 冷启动进度 | 供给增长被当成需求增长宣传 |
| 需求侧付费收入（DePIN） | 外部客户支付 | 生死指标 | 用排放补贴的内部消耗冒充 |
| 节点回本周期（DePIN） | 硬件成本/月净收益 | 供给侧稳定性 | 按 token 峰值价计算回本 |
| 需求/供给利用率（DePIN） | 已售资源/总供给 | 供需匹配度 | 个位数利用率是行业常态，如实写 |

必须优先披露的 6 个指标：去农民 DAU、D30 留存、真实付费收入（协议口径）、（链游）经济平衡表、（DePIN）需求侧收入与利用率、获客真实成本（含激励）。

## 5. Token economics 剖析

- **激励预算表**：token 排放中用于用户/供给补贴的比例与递减曲线——补贴退坡时点 = 真实需求的压力测试时点，排进里程碑登记。
- **双 token 结构**（链游常见）：治理币 + 游戏内币的兑换与销毁机制——游戏内币无限增发时，价值全靠治理币回购意愿，写明传导链条。
- **DePIN 的 BME 模型**（burn-and-mint equilibrium）：客户付费烧 token、节点挖 token——检验烧/铸比例的真实历史值，铸远大于烧 = 网络仍在净补贴期。
- **NFT 资产的地板价依赖**：以 NFT 销售为主要收入的项目，把地板价敏感性做进情景。
- 红旗阈值同 `valuation-private.md` 第 4 节，另加：**排放中补贴占比 >70% 且无递减计划**。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行，本附录特化：

### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 3 年后真实 MAU/需求收入 | | | | 留存外推+品类基准 |
| ARPU / take rate | | | | Web2 同类锚 |
| 补贴退坡后留存率 | | | | 激励间歇期证据 |
| 退出倍数（FDV/收入 或 用户价值） | | | | 二级锚 |
| 情景概率 | | | | 证据强度 |

1. **用户价值倍数**：FDV/真实 MAU 对照 Web2 同品类（游戏/社交）的每用户价值区间——crypto 溢价必须给理由（变现率更高？还是纯叙事）。
2. **收入倍数**：有真实协议收入的用 FDV/收入，锚定二级游戏/消费公司与流通 token 同类。
3. **轮次 comps**：同品类近 18 个月私募轮；本赛道估值受爆款周期影响剧烈（一个爆款带飞全品类估值 6–12 个月），标注周期位置。
4. **DePIN 特化**：需求侧收入倍数为主；供给侧网络重置成本（replacement cost）只作下限参考。
5. **反向检验**：本轮 FDV 隐含的 MAU/收入 vs 该品类 Web2+Web3 头部的真实分布。

### Peer set 规则

- 链游对照：Web3 同类 + Web2 同玩法品类（估值锚要双轨）。
- DePIN 按资源类型分桶（算力/存储/带宽/传感器），跨桶不可比。
- 必须纳入上一周期同模式的失败案例作 base rate 行。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 内容/玩法壁垒（链游） | 自研引擎/IP/长线内容管线，留存跑赢品类 | 换皮+tokenomics，生命周期 <6 个月 |
| 网络效应（消费/社交） | 关系链/创作者沉淀，多边增长飞轮 | 增长全靠积分，停发即散 |
| 资产协议标准（NFT/游戏资产） | 资产标准被生态采用，跨应用流通 | 封闭资产，协议无外部集成 |
| 供给侧规模（DePIN） | 供给密度形成服务质量壁垒（覆盖/延迟） | 供给同质化，补贴一停就迁移 |
| 需求合同（DePIN） | 企业级付费合同与续约记录 | 只有供给没有客户 |
| 品牌与社区 | 自传播、二创生态、KOL 自发 | 买量+机器人社区 |

## 8. 一级尽调红旗

- 留存数据只给激励期；拒绝提供 cohort 明细
- 链游经济系统无消耗端设计，白皮书回避通胀问题
- "游戏 demo"实为 CG 宣传片；核心玩法始终未上线
- DePIN 需求侧收入为零/接近零但供给侧融资叙事讲"网络增长"
- 节点销售收入被计为"营收"（本质是矿机销售，预支网络信用）
- NFT 首发销售依赖 KOL 白名单返利，二级地板价靠项目方回购托底
- 数据 dashboard 只在自家网站，无链上可验证路径
- 团队来自上一周期同模式失败项目且叙事换皮未披露
