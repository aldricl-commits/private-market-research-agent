## 1. 使用原则

- DeFi 是一级市场里**财务最透明**的赛道：fees、收入、用户、留存全部链上可查。因此本附录标的的数据可得性等级应达到 A/B——达不到说明研究不到位，而不是数据不存在。
- 核心分析对象是**协议的损益表**：`真实费用（用户付） − 流动性成本（给 LP/存款人的分成） − 激励支出（token 排放） = 协议真实盈余`。多数 DeFi 协议在激励口径下是亏损的，把 token 排放算进成本是本附录的硬性要求。
- 区分**费用（fees）与收入（revenue）**：fees 是用户付的全部，revenue 是归协议/token 的部分。两者的比值（take rate 的协议留存率）是价值捕获的核心变量。
- 永远做**激励净化**：TVL、交易量、用户数在激励期与非激励期分开看；激励结束后的留存才是产品力。
- 可组合性是双刃剑：TVL 中有多少是循环杠杆（同一笔资金反复质押）？用协议原生口径拆解。

## 2. 信息来源与链上核验

- **DefiLlama**：TVL、fees、revenue、激励支出（emissions）——首选口径，免费 API 可拉历史。
- **Token Terminal**：标准化 P/S、GMV、take rate，适合与二级锚同口径对比。
- **Dune**：定制核验——真实用户数（去女巫）、交易量分布（top 地址集中度）、留存 cohort。
- **协议自有 dashboard**：口径常美化（把激励算进 APY 吸储），一律与 DefiLlama 交叉。
- **治理论坛/snapshot**：fee switch 讨论、金库支出、与做市商的协议——重大治理提案是"准财报"。
- **审计与安全**：审计次数与机构、历史漏洞与赔付记录、bug bounty 规模、oracle 依赖。
- 交易量核验：对比 CEX 同交易对深度与价差——链上报告量远超合理套利空间 = wash trading 嫌疑。

## 3. 价值驱动树

```text
协议价值 =
  交易/借贷需求总量（外生真实需求）
  × 协议市占率（流动性与路由的选择）
  × 有效 take rate（费率 × 未被返佣/聚合器截留的比例）
  × 协议留存率（fees 中归协议的比例）
  − token 激励支出（获取 TVL/交易量的真实成本）
  × 需求持续性系数（牛熊周期的收入弹性）
```

报告中至少回答：

- 需求是外生的（真实交易/借贷）还是内生的（挖矿循环、积分农场）？占比多少？
- 停掉激励，TVL 和交易量会留下多少？（找历史激励结束的自然实验）
- 聚合器/前端截流：用户直接来还是被 1inch/钱包路由来的？路由来的份额随时会走。
- fee switch 状态：协议赚的钱现在归谁？开了会不会引发流动性迁移？
- 牛熊弹性：熊市里该品类的费用收缩幅度（对照上一周期同类协议收入曲线）。

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| TVL | 协议锁定资产总值 | 规模与信任基数 | 循环杠杆重复计数；激励租用；币价波动混入 |
| 真实费用（fees） | 用户支付的交易费/利差/清算费 | 需求货币化 | 自家 token 计价；激励期冲量 |
| 协议收入（revenue） | fees × 协议留存率 | 价值捕获现值 | fee switch 未开时为 0，要与"潜在收入"分开写 |
| 激励支出（emissions） | token 排放的美元价值 | 获取增长的真实成本 | 用排放时价还是现价要写明 |
| 净盈余 | revenue − emissions | 协议真实盈利能力 | 多数为负；转正时点是关键里程碑 |
| fees/TVL | 单位资金产出 | 资本效率与同类对比 | 高杠杆品类天然高，跨品类不可比 |
| 交易量/TVL | 周转率 | 真实使用强度 | wash trading 直接污染 |
| 有效 take rate | fees / 交易量 | 定价能力 | 竞争降费趋势；VIP 返佣后的净费率 |
| 用户留存 cohort | 按首次交互月分组的留存 | 产品力 vs 空投农民 | 快照后断崖=农民占比高 |
| 大户集中度 | top 10 地址占 TVL/交易量比 | 需求脆弱性 | 做市商地址与关联方识别 |
| 坏账率（借贷） | 未清算坏账/TVL | 风控质量 | 极端行情才暴露；查历史清算事件表现 |

必须优先披露的 6 个指标：fees（90 天均值）、revenue 口径与 fee switch 状态、emissions、净盈余趋势、激励净化后的 TVL/交易量、用户留存。

## 5. Token economics 剖析

- **价值捕获机制清单**：fee 分配（ve 模型/质押分红）、燃烧、治理——逐项标"已上线/承诺/无"。无捕获机制的 token，协议收入倍数只能作参照，写明估值本质是治理权+捕获预期。
- **ve/质押模型**：锁仓换收益的模型要算**真实收益率来源**——分的是 fees（可持续）还是排放（庞氏结构）？real yield 占比是关键指标。
- **供给压力**：`scripts/token_economics.py` 跑 unlock 表；DeFi 协议 token 的投资人/团队解锁高峰常与 fee switch 开启的利好公告重叠——警惕出货配合。
- **红旗阈值**：同 `valuation-private.md` 第 4 节。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行，本附录特化：

### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 3 年后年化 fees | | | | 品类规模 × 份额 |
| 协议留存率（fee switch） | | | | 治理路径 |
| 净盈余转正时点 | | | | emissions 递减表 |
| FDV/fees 退出倍数 | | | | 二级锚分位 |
| 情景概率 | | | | 证据强度 |

1. **FDV/fees 与 FDV/revenue 倍数**：二级锚充足（主流 DEX/借贷/perp 协议的流通 token），取同品类 3–5 个锚的倍数分布；标的按增速与净盈余质量给分位。
2. **轮次 comps**：近 18 个月同品类私募轮；DeFi 私募估值对"上一个类似成功者"锚定强，标注叙事溢价。
3. **协议 P&L 折现**（数据成熟时）：`(fees × 留存率 − emissions)` 的正常化路径，粗折现作交叉验证；不作主法。
4. **反向检验**：本轮 FDV 隐含的 fees 排名 vs 当前该排名协议的真实 fees。

### Peer set 规则

- 按品类分桶（现货 DEX / perp / 借贷 / 收益），跨品类只作大盘参照。
- 每桶至少含一个"上一周期活下来的"与一个"归零的"，给 base rate。
- pre-launch 标的：可比项目**上线 FDV vs 当前 FDV**两列并列，提示上线即巅峰风险。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 流动性网络效应 | 深度最优→路由默认→更深流动性的飞轮已成 | 深度靠排放租用，APY 一降就走 |
| 集成与可组合性锁定 | 被主流协议作为底层集成（清算/抵押品/预言机依赖） | 集成可一键替换，无独占性 |
| 风控与安全记录 | 多次极端行情零坏账/零事故；审计+实战双重记录 | 未经历过压力行情；靠审计报告背书 |
| 品牌与默认心智 | 品类代名词；前端直接流量占比高 | 流量全靠聚合器路由，无自有心智 |
| 机制创新壁垒 | 机制被验证且先发积累（流动性/数据/集成）拉开代差 | 机制可 fork，fork 者用更高排放抢流动性 |
| 团队持续迭代 | 多个版本持续领先，跟进者始终慢一代 | 一版吃老本，创新停滞 |

DeFi 的默认假设是**可 fork、护城河弱**；任何"强护城河"结论必须解释为什么历史上的 fork 都没成功。

## 8. 一级尽调红旗

- APY 主要由自家 token 排放构成且以排放时价宣传（庞氏结构未披露）
- 交易量/TVL 异常高但 top 地址集中——做市商刷量或关联方循环
- 金库支出不透明；治理提案由团队多签绕过投票执行
- 与做市商的 token 借贷协议条款不披露（上线砸盘风险）
- 审计机构小众且报告日期在重大代码变更之前
- oracle 依赖单一且可操纵（历史上同结构协议被攻击过）
- 团队在 fee switch/大利好公告前后有链上出货行为
