## 1. 使用原则

- 内容公司是 IP 组合，不是一条平滑收入曲线。拆分存量 IP、在运营内容、新项目、分发平台和授权权益。
- 用户规模必须与留存、付费率、ARPPU/ARPU 和内容成本共同看；下载、观看或 MAU 单独增长不创造价值。
- 区分内容开发支出、资本化和摊销政策。现金投入与会计利润的时间错配必须还原。
- 需要考虑单款IP收入贡献的集中度，分游戏lifecycle不一样，MOBA最长，SLG，三消都属于lifecycle较长的，MMORPG则较短，需要判断主要IP处于lifecycle的什么位置，是否有长青的可能。单部爆款不可直接永续化；使用 cohort、续作率、片单概率和历史命中基准率。

## 2. 信息来源与公允机制

1. 公司申报、内容成本/摊销附注、授权与分账合同披露。
2. 平台原始榜单、用户与销售数据、当地票房/出版/广电监管统计。
3. 游戏商店、电视/流媒体测量和行业协会数据；第三方估算说明覆盖偏差。
4. IP 权属、诉讼、工会、版号和内容监管原文。

## 3. 价值驱动树

```text
游戏收入 = 活跃用户 × 付费率 × ARPPU + 广告 + 授权
订阅媒体收入 = 订户 × ARPU × (1 - churn)
影视/IP 收入 = 项目受众 × 单位变现 × 权益比例 + 长尾授权
内容价值 = 生命周期现金流 - 开发/营销投入 - 平台/人才分成
```

## 4. 核心 KPI 字典

| 细分 | 必看 KPI | 口径陷阱 |
|---|---|---|
| 游戏 | DAU/MAU、留存、付费率、ARPPU、流水、递延收入 | 流水与确认收入混用；买量用户质量 |
| 流媒体 | 订户净增、ARPU、churn、观看时长、内容现金支出 | 促销订户、捆绑与地区 mix |
| 影视/出版 | 项目片单、票房/销量、分账率、内容摊销、库存 | 单部爆款外推；权属比例忽略 |
| IP 授权 | 授权收入、最低保底、续约率、品类/地区扩张 | 预收和一次性保底冒充经常收入 |

## 5. 财务模型结构

- 按 IP/产品 cohort 建生命周期曲线，存量与新项目分开。
- 内容项目采用概率加权预算、上线时间、变现和长尾；延期不只平移收入，也改变营销和竞争窗口。
- 把内容现金投入、资本化、摊销与收入确认做桥接。
- 订阅模型拆订户、净增、churn、ARPU 与内容成本/订户。

## 6. 估值方法

- 成熟订阅/游戏：DCF、EV/EBITDA、EV/订户或用户只作交叉验证。
- 内容集团：按 IP、网络、流媒体、授权和资产 SOTP。
- 早期项目：概率加权项目 NPV；不把未立项续作纳入基准价值。
- 周期性广告和票房利润用正常化利润，不用峰值 P/E。

## 7. 护城河与竞争判断

检验 IP 复用能力、创作者关系、分发控制、社区网络、推荐数据和跨媒介变现。单一爆款、不可持续买量或依赖第三方平台不构成宽护城河。
