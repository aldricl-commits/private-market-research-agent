# CeFi 与交易所行业附录（一级视角）

适用范围：中心化交易所（现货/衍生品）、托管机构、prime brokerage、做市商、OTC 服务台、机构交易基础设施、财富管理类 CeFi。链上交易协议走 `crypto-defi`；资本市场基础设施框架可参 `capital-markets` 作次附录。

## 1. 使用原则

- CeFi 是 crypto 里**最接近传统金融的生意**：收入 = 交易量 × take rate + 利息/借贷 + 托管费 + 上币与增值服务。分析框架接近券商+交易所混合体，但**对手方风险与资金托管是第一问**——FTX 之后，任何 CeFi 研究先回答"客户资产在哪、怎么隔离、谁审计"。
- 收入结构必须拆分：现货 vs 衍生品（费率差 5–10 倍）、散户 vs 机构（费率与粘性完全不同）、交易收入 vs 利息收入（利率敏感）。只给总量的按 C 级数据处理。
- **交易量刷量是行业地方病**：非头部交易所的报告量普遍虚高。用第三方调整口径与深度/价差数据净化后再进任何计算。
- 牌照版图 = 可服务市场：分法域列牌照（美 MSB/州牌照、欧 MiCA、港 VASP、新 MAS、迪拜 VARA），"注册"≠"持牌"≠"可展业"。
- 周期弹性极大：交易收入在熊市可缩 70–90%。估值必须用跨周期正常化收入，不用牛市峰值。

## 2. 信息来源与核验

- **交易量**：CoinGecko/CoinMarketCap 交易所页（有调整分）、The Block Legitimate Volume 类口径、Kaiko 深度数据；自查订单簿深度 vs 报告量的合理性。
- **储备证明（PoR）**：链上储备地址（可验证）+ 负债审计（多数不做，标注缺口）——只有资产端的 PoR 不能证明偿付能力。
- **牌照**：各监管官网名单直接核对（FinCEN MSB、NYDFS、MAS、SFC/HKMA、VARA）。
- **安全记录**：历史被盗事件与赔付处理；保险基金规模（链上可查的如实标注）。
- **做市商**：交易量与持仓无公开数据，依赖 data room；外部佐证=交易所 VIP 层级、行业排名传闻标 `[未验证]`。
- **利息/理财业务**：收益来源穿透（放贷给谁、抵押率）——Celsius/BlockFi 的教训是收益来源讲不清=庞氏结构候选。

## 3. 价值驱动树

```text
CeFi 价值 =
  交易量（净化后，现货+衍生品分列）
  × 混合 take rate（产品结构 × 客户结构 × VIP 折扣后）
  + 客户资产规模 × 利息净差（借贷/理财/staking 分成）
  + 托管/上币/增值服务收入
  − 合规成本（随牌照版图扩大而上升）
  − 安全与保险成本
  × 信任存续系数（托管透明度 × 监管地位 × 安全记录）
```

报告中至少回答：

- 客户资产隔离结构：法律实体、托管方、能否被挪用？负债端有没有审计？
- 收入的周期正常化：熊市年份的收入是多少？固定成本能否穿越熊市？
- 客户获取依赖什么：上币效应、返佣联盟、衍生品杠杆？各自的监管脆弱性？
- 头部集中趋势下（流动性向头部集中），标的作为非头部靠什么活：区域牌照、细分产品还是机构服务？
- 利息业务的收益从哪来，极端行情下坏账传导路径？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 现货交易量（净化） | 调整口径日均量 | 规模基数 | 刷量；返佣自成交 |
| 衍生品交易量与持仓 | 日均量与 OI | 高毛利业务规模 | OI 与量的比例异常=刷量信号 |
| 混合 take rate | 净交易收入/总交易量 | 定价能力 | VIP 折扣后实际费率远低于牌价 |
| 客户资产规模（AUC） | 托管客户资产 | 利息与理财业务基数 | 含自营资产虚增；快照冲高 |
| 活跃交易用户 | 月度去重 | 用户基数与获客效率 | 注册数冒充活跃数 |
| 利息净差 | 利息净收入/生息资产 | 第二收入曲线 | 收益来源穿透不了=红旗 |
| 保险基金/自有资本 | 链上或审计口径 | 风险缓冲 | 用平台币计价虚增 |
| 牌照数与法域 | 持牌清单 | 可服务市场与合规成本 | 注册冒充牌照 |
| 收入分布（法域/产品） | 分部收入 | 监管集中度风险 | 灰色法域收入占比讳莫如深 |
| 净流入资金 | 链上出入金净额 | 信任的资金投票 | 大户单笔扰动，看趋势 |

必须优先披露的 6 个指标：净化交易量（现货/衍生品分列）、混合 take rate、AUC 与托管结构、牌照清单、收入的法域分布、熊市年份收入。

## 5. Token economics 剖析

- **平台币三问**：(a) 折扣/回购/销毁机制的现金流含量——回购销毁是真分红，手续费折扣是营销费用；(b) 平台币在自家风控中的角色——拿平台币当保证金/保险基金=风险自指涉（FTT 结构）；(c) 监管定性——平台币是最容易被认定证券的类别之一。
- 投 equity 还是平台币：exchange 的 equity 与平台币价值关联松散，报告必须写清投的是哪层、两层间的利益输送机制（回购承诺、利润分配）。
- `scripts/token_economics.py` 跑平台币供给与回购净额对比。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行，本附录特化：

### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 正常化年交易量 | | | | 跨周期均值 |
| 混合 take rate | | | | 竞争与结构 |
| 正常化收入与净利率 | | | | 成本结构 |
| 退出倍数（P/E 或 P/S） | | | | 二级锚折价 |
| 情景概率 | | | | 证据强度 |

1. **二级锚**：上市交易所与经纪商（Coinbase 及传统交易所/券商）——CeFi 赛道二级锚最硬，P/S 与 P/E 双口径，按标的的牌照成色、收入质量折价。
2. **正常化 P/E**：有利润的标的用跨周期正常化利润（牛熊平均），不用单年。
3. **轮次 comps**：同类 CeFi 私募轮——注意监管周期对估值影响剧烈（合规溢价/打压折价），标注政策环境。
4. **SOTP**（业务多元时）：交易/托管/理财/做市分部估值加总。
5. **反向检验**：本轮估值隐含的交易量份额 vs 当前头部所份额分布。

### Peer set 规则

- 散户所与机构服务商分开建表；持牌与离岸分开。
- 二级锚折价说明：托管透明度、牌照差距、客户集中度。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 流动性网络效应 | 深度最优→点差最小→大户聚集的飞轮；衍生品 OI 领先 | 深度靠做市补贴，补贴停即散 |
| 牌照与合规壁垒 | 关键法域全牌照 + 多年合规记录 | 离岸监管套利，随时被逐出市场 |
| 信任与安全记录 | 多年零事故 + 透明托管 + 负债审计 | 无审计；历史挪用传闻未澄清 |
| 机构服务粘性 | prime/托管/结算深度绑定机构工作流 | 纯散户业务，切换成本≈0 |
| 品牌与心智 | 区域市场默认入口 | 靠返佣买量，停返佣即流失 |
| 成本结构 | 技术自研、单位撮合成本低 | 白标系统，无技术差异 |

## 8. 一级尽调红旗

- 客户资产与自营混同；负债端无审计；PoR 只晒资产
- 平台币作为保证金/保险基金/抵押品（FTT 结构复现）
- 理财收益来源穿透不了、或依赖单一借款方
- 报告交易量与订单簿深度严重背离
- 收入主要来自监管灰色法域且无合规路径
- 关联做市商（团队自设）承担主要流动性且条款不披露
- 高管来自暴雷平台且岗位与暴雷业务直接相关、未披露
- 用"即将拿到牌照"作为融资叙事但无申请记录可查
