# 稳定币与加密支付行业附录（一级视角）

适用范围：稳定币发行方（法币抵押/加密抵押/合成）、稳定币基础设施（发行即服务、清算网络）、加密支付网络与收单、出入金通道（on/off-ramp）、跨境汇款、加密卡。传统支付公司走 `payments-fintech`（本附录常与其互为次附录）。

## 1. 使用原则

- 本赛道的两种截然不同的生意，先分清再研究：
  - **发行方**：商业模式 = 储备资产的利息收入（float income）− 分销成本（给渠道/持有人的分成）。本质是货币基金 + 网络，利率敏感性极高。
  - **支付网络/通道**：商业模式 = 交易量 × take rate − 通道成本。本质是收单/清算生意，看量与费率。
- 发行方研究的第一问是**储备质量与赎回机制**（能不能 1:1 刚兑），第二问才是增长。任何绕过第一问的增长故事直接降级。
- **真实交易量净化是本附录的核心功课**：链上稳定币转账量的大头是交易所内部划转、做市商调仓、MEV。必须用调整口径（如 Visa/Allium 的 adjusted volume 方法：去 bot、去内部划转）估算真实支付量。
- 利率情景是发行方估值的第一变量：把"当前利率下的收入"外推为永续是最常见错误，必做降息情景。
- 监管是结构性变量不是风险附注：GENIUS Act（美）、MiCA（欧）、香港稳定币条例、新加坡 PSA——标的的牌照版图直接决定可服务市场。

## 2. 信息来源与核验

- **供应量与链分布**：DefiLlama stablecoins 页、各链浏览器——发行量、链分布、增速全部链上可查 `[链上]`。
- **储备结构**：发行方月度 attestation（注意 attestation ≠ audit，会计师"核对快照"与审计意见的可信度差一档，报告中标注）；托管行与国债持仓披露。
- **真实交易量**：Allium/Visa onchain analytics 口径、Artemis 调整口径；自建 Dune 查询去 bot。
- **分销协议**：发行方与交易所/钱包的分成协议（Circle-Coinbase 类结构）——一级尽调核心问题，公开信息少，data room 必查项。
- **牌照**：各法域监管名单（NYDFS、MAS、FCA、HKMA）官网核对声称的牌照类型与范围——"申请中"与"持有"严格区分。
- **支付通道**：处理量声称与银行合作方交叉验证；卡业务查卡组织（Visa/MC）的 principal member vs program manager 身份。

## 3. 价值驱动树

**发行方**：

```text
发行方价值 =
  流通供应量（float）
  × 储备净收益率（利率环境 × 储备久期结构）
  × (1 − 分销分成率)（给渠道/持有人的让利）
  + 增值服务收入（清算 API、跨链、企业账户）
  − 合规与储备管理成本
  × 监管存续系数（牌照版图 × 刚兑记录）
```

**支付网络/通道**：

```text
网络价值 =
  真实支付/汇款交易量（净化后）
  × 净 take rate（毛费率 − 通道与合规成本）
  × 交易量留存与复购（B2B 客户续约/C 端月活）
  × 牌照与银行关系的可复制难度
```

报告中至少回答：

- （发行方）降息 200bp，收入掉多少？分销分成是固定还是浮动？
- （发行方）极端赎回情景：单日赎回 20% 能否兑付？储备久期错配多大？
- （通道）量从哪来：投机出入金还是真实商业支付？周期弹性差别巨大。
- （通道）银行关系集中度：失去主力合作行的替代方案？
- 稳定币"发行即服务"化后，标的的份额靠什么守（分销网络还是牌照）？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 流通供应量 | 链上可查的发行量 | 发行方规模基数 | 多链重复计数；桥接包装资产混入 |
| 供应量份额与增速 | 占全稳定币比 | 竞争位置 | 单一链激励拉动的暂时份额 |
| 真实支付量 | 调整口径（去 bot/内部划转） | 网络的真实使用 | 原始链上量虚高 5–10 倍是常态 |
| 储备净收益率 | 储备收入/平均 float | 发行方核心盈利 | 用峰值利率外推 |
| 分销分成率 | 付给渠道的分成/总收入 | 真实留存收入 | 头部渠道议价权上升会挤压 |
| 净 take rate（通道） | 净收入/交易量 | 定价能力 | 促销期费率不可持续 |
| 持有人结构 | 交易所/DeFi/钱包直持比例 | 需求粘性 | 交易所持有=投机需求，利率敏感 |
| 赎回时效记录 | T+0/T+1 兑付历史 | 刚兑可信度 | 压力时期才见真章，查脱锚历史 |
| 牌照版图 | 各法域牌照类型清单 | 可服务市场 | "申请中"冒充"持有" |
| 月活跃支付账户 | 去重付款方 | C 端/B 端渗透 | 空投/返现拉新的活跃不可持续 |

必须优先披露的 6 个指标：流通供应量与份额、真实支付量（调整口径）、储备结构与 attestation 频率、分销分成结构、牌照清单、赎回记录。

## 5. Token economics 剖析

- 多数发行方/通道是 **equity 生意**，token 若存在先问"这个 token 在钱流里承担什么"——治理币无现金流捕获的按 `crypto-defi` 第 5 节纪律处理。
- 合成/算法型稳定币的"稳定机制"本身就是研究对象：抵押率、清算机制、极端行情的死亡螺旋路径；上一周期算稳崩盘案例作 base rate。
- 收益型稳定币（yield-bearing）注意证券化风险：给持有人付息在多数法域触发证券认定，牌照结构必须能容纳。
- 投 equity 还是 token 要在报告中写清，两者价值可能完全割裂。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行，本附录特化：

### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 3 年后流通供应量/交易量 | | | | 份额 × 行业增速 |
| 净收益率（含降息情景） | | | | 利率路径 |
| 分销分成率走势 | | | | 渠道议价权 |
| 退出倍数（P/S 或 P/E） | | | | 二级锚 |
| 情景概率 | | | | 证据强度 |

1. **发行方**：储备收益模型（float × 净收益率 × 留存比例）→ 类货币基金/银行的 P/E 框架；二级锚：上市稳定币发行方与支付公司。利率情景必做三档。
2. **通道/网络**：P/S 与 EV/交易量，锚定上市支付公司（`payments-fintech` 附录的锚）打折价；真实量净化后再算倍数。
3. **轮次 comps**：近 18 个月稳定币/支付赛道私募轮——监管利好后估值通胀明显，标注政策周期位置。
4. **反向检验**：本轮估值隐含的 float/交易量 vs 当前头部玩家的量级（"隐含成为第 N 大发行方"）。

### Peer set 规则

- 发行方与通道分开建表；法币抵押与合成分开。
- 二级锚含传统支付公司时标注生意模式差异（发行方是利差生意不是支付生意）。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 分销网络 | 独家/深度渠道绑定（交易所、钱包、银行）且分成可控 | 渠道随时可换发行方，分成被越挤越高 |
| 流动性网络效应 | 全链深度交易对与 DeFi 集成密度第一梯队 | 靠激励维持的流动性 |
| 牌照壁垒 | 关键法域先发牌照 + 合规团队与监管关系 | 牌照可申请，先发窗口 12–24 个月会关闭 |
| 刚兑信用记录 | 多次压力事件零脱锚/快速恢复 | 无压力记录；储备透明度低 |
| 银行关系 | 多元且深度的银行/托管关系 | 单一银行依赖（历史上是致命单点） |
| 成本结构 | 规模化后合规与储备管理的单位成本优势 | 无规模，成本率随监管加码上升 |

## 8. 一级尽调红旗

- 储备只出 attestation 不出审计、或 attestation 机构频繁更换
- 储备中含关联方资产、自家 token 或高久期错配未披露
- 声称的牌照实为"豁免/申请中/合作方持牌"
- 交易量与银行/卡组织侧数据对不上（刷量或计口径游戏）
- 分销协议把大部分经济利益让给单一渠道且有排他+短约（渠道随时反水）
- 团队来自上一个脱锚/暴雷项目且未披露
- 收益来源讲不清（"链上策略收益"实为循环挖矿或期限错配）
