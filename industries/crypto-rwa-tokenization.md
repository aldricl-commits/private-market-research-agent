## 1. 使用原则

- RWA 的本质是**资管/发行生意穿了链上外衣**：收入 = AUM × 费率（管理费/发行费/赎回费/利差）。研究框架接近资管公司，链上只是分销与结算通道。**先用资管框架算账，再评估"链上"带来的增量**（7×24 结算、可组合性、全球分销）是否真实变现。
- **法律结构是第一尽调对象**：token 持有人对底层资产的索取权是直接所有权、SPV 份额、还是发行方的无担保债权？破产隔离有没有做？监管法域是哪里？这三问不过关，AUM 增长毫无意义。
- 区分**AUM 的质量**：自然增长的第三方资金 vs 关联方/做市资金充数；机构客户 vs DeFi 协议金库（后者是真实需求但集中度高）。
- 收益率叙事的净化：代币化国债的收益来自底层利率，不是项目的本事；项目真正的收入是费率。把"AUM 高增长"翻译成"费率收入"后很多项目瞬间变小。
- 对照传统同业的费率压缩史：货币基金/ETF 的费率战 base rate 提示 RWA 费率的长期走向。

## 2. 信息来源与核验

- **链上 AUM**：RWA.xyz、DefiLlama RWA 分类——发行量、持有人数、链分布 `[链上]`；与发行方公告交叉。
- **底层资产验证**：托管方与审计报告；代币化国债查底层基金的 SEC 申报（若为注册产品）；私募信贷查借款人池的披露粒度。
- **法律结构**：发行文件（PPM/招募说明书）、SPV 注册地与结构图——data room 必查，公开缺失时按 C 级处理并列为关键缺口。
- **持有人结构**：链上地址分布——前 10 持有人占比、是否关联地址、DeFi 协议金库占比。
- **赎回记录**：赎回时效与门槛（T+0 还是 T+N、最小赎回额、gate 条款）；历史赎回压力事件表现。
- **牌照**：发行法域的证券/集合投资牌照核对（SEC Reg D/S、新加坡 MAS、欧盟证券化条例、香港 SFC）。

## 3. 价值驱动树

```text
RWA 平台价值 =
  链上 AUM（净化后：剔除关联方充数）
  × 净费率（管理费+发行费−分销让利）
  × AUM 增长可信度（分销渠道 × 需求方真实性）
  × 费率防御力（对照传统费率压缩曲线）
  + 基础设施/牌照的平台价值（发行即服务的第三方收入）
  × 法律结构稳健系数（破产隔离 × 监管合规度）
```

报告中至少回答：

- 需求方是谁：DeFi 金库配置、crypto 原生机构的闲置资金、还是真实的传统资金上链？各占多少，各自的留存逻辑？
- 净费率是多少？对照同类传统产品（货币基金 ~10–20bp、私募信贷 1–2%）处于什么位置，凭什么守住？
- 利率下行情景：代币化国债的需求（追收益的闲置稳定币）会不会随利率消失？
- 平台故事 vs 单一产品：是"发行基础设施"还是就是一只链上基金？平台收入（第三方发行）占比多少？
- 可组合性变现了吗：作为 DeFi 抵押品/保证金的集成数量与带来的 AUM。

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 链上 AUM | 发行量 × 净值 | 规模基数 | 关联方充数；重复计数（跨链桥接） |
| AUM 净流入 | 剔除净值变动的真实申购 | 增长质量 | 用币价/利息滚存冒充流入 |
| 净费率 | 费收入/平均 AUM | 盈利能力核心 | 引流期零费率不可持续 |
| 持有人数与集中度 | 去重地址；前 10 占比 | 需求分散度 | 女巫地址拆分伪装分散 |
| 第三方发行收入 | 平台服务费 | 平台化验证 | 关联发行方冒充第三方 |
| 赎回时效与记录 | T+N 与压力事件表现 | 流动性承诺可信度 | 条款里的 gate/暂停权 |
| DeFi 集成数 | 作为抵押品/组件的集成 | 可组合性变现 | 集成数≠使用量，查真实调用 |
| 底层资产收益率与利差 | 底层收益 − 付给持有人 | 利差型收入 | 期限错配与信用下沉未披露 |
| 违约/减值记录（信贷类） | 底层借款人违约率 | 资产质量 | 展期掩盖违约 |
| 牌照与法域清单 | 持牌类型 | 可服务市场 | 豁免额度冒充牌照 |

必须优先披露的 6 个指标：净化 AUM 与净流入、净费率、持有人集中度、法律结构（索取权+破产隔离）、赎回条款与记录、（信贷类）底层违约率。

## 5. Token economics 剖析

- **两层 token 要分开**：资产 token（代表底层资产份额，价值=净值，没有"估值"问题）与平台/治理 token（捕获费收入的才有估值意义）。研究对象是后者；混同两者的项目沟通水平本身是红旗。
- 平台 token 的价值捕获：费收入分配/回购机制是否上线；无机制的按 `crypto-defi` 第 5 节纪律处理。
- 资产 token 的"收益增强"结构（再质押、循环抵押）：每层增强都在加对手方风险，穿透列出风险链条。
- equity vs token：RWA 平台多为 equity 主体（牌照在公司），token 常是分销激励——投资标的写清是哪层。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行，本附录特化：

### 估值假设表

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 3 年后链上 AUM | | | | 赛道渗透 × 份额 |
| 净费率 | | | | 传统费率锚 |
| 费收入与平台收入占比 | | | | 平台化进度 |
| 退出倍数（P/S 或 % of AUM） | | | | 二级资管锚 |
| 情景概率 | | | | 证据强度 |

1. **资管框架为主**：估值 = 费收入 × P/S 倍数，或 AUM × 行业"% of AUM"经验区间——二级锚用上市资管/ETF 发行商，按阶段与费率质量折价。
2. **轮次 comps**：RWA 赛道近 18 个月私募轮——监管利好驱动的估值通胀明显，标注政策周期。
3. **平台期权**：发行即服务的第三方收入若已验证，可单列平台倍数；未验证只作期权不进 base case。
4. **反向检验**：本轮估值隐含的 AUM（按合理 % of AUM 倒推）vs 当前整个 RWA 品类的总 AUM——"隐含吃下品类 X%"是否可信。

### Peer set 规则

- 按底层资产分桶：国债/货基类、私募信贷类、另类资产类——费率与风险完全不同，不混桶。
- 二级锚标注生意模式差异（传统资管无 24/7 结算成本，也无智能合约风险）。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 牌照与法律结构先发 | 关键法域完整牌照 + 经过验证的破产隔离结构 | 靠豁免展业，结构未经压力测试 |
| 分销网络 | 深度绑定主流 DeFi 协议金库/钱包/交易所 | 单一渠道依赖 |
| 机构信任 | 头部传统机构合作发行且可验证 | "洽谈中"的 logo 墙 |
| 流动性与集成密度 | 作为抵押品的集成最广、二级深度最好 | 集成空挂无使用量 |
| 费率防御 | 差异化服务（合规/结构化）支撑费率 | 纯通道生意，费率竞争到底 |
| 规模成本优势 | AUM 规模摊薄合规与运营成本 | 规模小成本率高，增长靠烧钱 |

## 8. 一级尽调红旗

- 说不清 token 持有人对底层资产的法律索取权；无破产隔离结构
- 底层资产托管方/审计方与发行方关联
- AUM 主要由关联方/自有资金充数；净流入长期为负但宣传"AUM 创新高"（靠利息滚存）
- 私募信贷类：借款人池不披露、展期率异常、收益率显著高于同类却讲不清风险来源
- 赎回条款含宽泛的暂停权/gate 且未向投资人主动披露
- 监管套利结构（离岸发行+美国用户实质可及）
- 把底层利率收益宣传成平台盈利能力
