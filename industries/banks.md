# 银行业深度研究附录

适用于商业银行、零售银行、投行/交易型银行、区域银行、数字银行及银行控股公司。银行的负债是经营原料，不能机械套用工业企业 EV/EBITDA 或普通 FCF。若公司同时有大额保险、资产管理或非银消费金融业务，先按分部拆分利润与资本占用，再只对银行部分使用本附录。

## 1. 使用原则

- 先确定这是不是一家真正的银行：收入必须以存贷利差和银行牌照业务为主。以交易、资管、支付或消费信贷为主的机构，应改用对应附录并单独处理资本占用。
- 银行研究的核心不是利润增速，而是**风险调整后的资本回报能否跨周期维持**。高 ROE 若来自高杠杆、低拨备或激进承销，不构成价值。
- 区分零售银行、企业银行、区域银行、全能银行、投行型银行和数字银行。存款结构、信用周期敏感度、费用结构和估值中枢完全不同。
- 对于银行，宏观周期也非常关键，需要确认当下的宏观周期（加息环境，降息环境，利差打开，利差缩窄，久期风险敞口变化可能，etc.）
- 会计口径与监管口径必须桥接。IFRS 9 三阶段与美国 CECL 的拨备逻辑不同，跨市场横比前先说明差异。
- 所有资产质量结论必须建立在**迁徙证据**上（逾期→关注→不良→核销），不能只看时点不良率。
- 利润表的信用成本是估计值，不是事实。任何"盈利改善"结论必须先回答拨备是否充足。

## 2. 信息来源与公允机制

### 来源优先级

1. **监管申报与资本披露**：Pillar 3 报告、年报/半年报、招股书。用于确认 RWA 构成、资本充足率、杠杆率、流动性指标、大额风险暴露和关联交易。
2. **监管数据库**：美国用 FFIEC Call Reports、FDIC BankFind、Federal Reserve Y-9C；欧洲用 EBA 透明度练习与 SSM 披露；中国用银保监会/人民银行统计；香港用 HKMA。全球资本口径参考 BIS Basel Framework。
3. **银行财报与补充表**：earnings release、supplemental financial information、investor presentation。用于获取 NIM 桥、存款量价、贷款分类、拨备勾稽和指引。
4. **电话会文字稿**：跟踪管理层对存款竞争、信用迁徙、CRE 暴露、监管资本和回购的措辞变化。
5. **同业披露与第三方**：用于建立 peer set 和合理区间；卖方研究只作补充，不得替代一手披露。

### 公允机制

- **口径优先**：NIM、不良、拨备覆盖率、CET1 的计算口径各家不同（是否含票据、是否含表外、是否用平均余额）。首次出现时写明定义，未披露则写"未获取到公司定义"。
- **监管口径与会计口径分开**：会计拨备、监管预期损失和经济损失是三件事。跨市场比较时必须说明使用的是哪一套。
- **盈利与风险并列**：任何"ROE 改善"结论必须同时给出资产质量、资本充足和存款稳定性的约束。
- **反证优先写入**：例如"信用成本正常化"必须绑定逾期率、关注类迁徙、coverage ratio 或前瞻宏观假设，而不是只引用管理层指引。
- **避免幸存者偏差**：peer set 必须同时纳入优质银行、周期受压银行和已出问题的同业，不能只选高 ROTCE 标的。
- **区分周期与结构**：NIM 收窄可能是利率周期，也可能是存款特许权流失。必须用 deposit beta、存款结构迁移和市场份额证据判断。

## 3. 银行价值驱动树

银行内在价值可以拆成：

```text
权益价值 =
  有形账面价值（TBV）
  × 可持续 ROTCE 相对权益成本的溢价
  × 跨周期资本内生能力
  × 存款特许权质量（成本、稳定性、久期）
  × 资产端定价与风险选择能力
  × 费用经营杠杆
  − 信用周期损失（跨周期均值，而非当期）
  − 监管资本约束与合规成本
  − 稀释、并购损耗与商誉减值
```

报告中尝试回答：

- 如果投资这家银行，我们实质是在投资什么？
- 利差来自资产端定价能力，还是仅仅是利率环境的被动结果？
- 存款是低成本、黏性、分散的核心存款，还是价格敏感的批发/大额存款？
- 当前信用成本相对跨周期均值处于什么位置？如果回归均值，盈利还剩多少？
- 资本富余是真实可分配的，还是建立在乐观的压力测试假设上？
- ROTCE 是否持续高于权益成本？若不是，增长是在毁灭价值。

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| NIM | 净利息收入 / 平均生息资产 | 核心盈利能力 | 是否用平均余额、是否含票据与同业，各家口径不同 |
| Asset yield | 生息资产收益率 | 资产端定价能力 | 结构变化（按揭 vs 信用卡）会掩盖真实定价 |
| Deposit beta | 存款成本变动 / 政策利率变动 | 利率传导与存款黏性 | 上行 beta 与下行 beta 不对称，需分别测算 |
| Cost of funds | 计息负债成本率 | 负债端压力 | 批发融资与存款需分列 |
| Loan/deposit ratio | 贷款 / 存款 | 流动性与增长空间 | 高存贷比在压力期放大流动性风险 |
| NPL / NPA ratio | 不良贷款 / 总贷款 | 资产质量时点水平 | 时点数掩盖迁徙；核销可人为压低 |
| Stage 2 占比 | IFRS 9 二阶段贷款占比 | 前瞻恶化信号 | 美国 CECL 无此分层，跨市场不可直接比 |
| Net charge-off rate | 净核销 / 平均贷款 | 已实现损失 | 核销时点由管理层掌握，需看迁徙配合 |
| Provision / avg loans | 信用成本率 | 当期计提强度 | 与跨周期均值比较才有意义 |
| Coverage ratio | 拨备 / 不良 | 缓冲厚度 | 高 coverage 若不良认定宽松则失真 |
| ACL / loans | 拨备余额 / 贷款 | 存量缓冲 | CECL 下受宏观预测假设影响大 |
| Efficiency ratio | 费用 / 营业收入 | 成本控制 | 收入波动会让该比率误导 |
| CET1 ratio | 核心一级资本 / RWA | 资本安全边际 | 需看 RWA density 是否被优化 |
| RWA density | RWA / 总资产 | 风险计量激进度 | 内评法可显著压低，需与标准法对比 |
| LCR / NSFR | 流动性覆盖率 / 净稳定资金比率 | 压力期生存能力 | 非所有市场强制披露 |
| 未保险存款占比 | 超出存保限额的存款占比 | 挤兑脆弱性 | 2023 年区域银行危机的核心指标 |
| ROTCE | 净利润 / 平均有形普通股权益 | 真实资本回报 | 商誉大的银行 ROE 与 ROTCE 差异显著 |
| TBVPS | 每股有形账面价值 | 价值复利基准 | 需加回累计分红才能看真实复利 |

需要优先披露的 8 个指标：NIM、deposit beta、贷款结构、Stage 2/逾期迁徙、信用成本率、coverage ratio、CET1、ROTCE 与 TBVPS 增长。

## 5. 财务模型结构

### 资产负债与收入模型

按可得数据从高到低选择驱动：

1. `平均生息资产 × 资产收益率 − 平均计息负债 × 负债成本 = 净利息收入`
2. 贷款簿分池建模：商业地产（办公/多户/零售）、C&I、按揭、信用卡、汽车、其他消费，各池给增速、收益率和信用成本。
3. 非息收入分列：手续费、财富管理、投行、交易、信用卡交换费、按揭服务。交易收入波动大，不得线性外推。
4. 披露不足时至少分零售/企业两段，不得只做总资产 CAGR。

最低预测要求：

- 至少 3 年历史、8 个季度历史。
- 未来 5 年显性预测，含利率路径假设（必须写明用的是哪条曲线）。
- 单列有机增长与并购影响；无法拆分时写"未获取到拆分"并降低置信度。
- 贷款簿至少拆商业地产、C&I、按揭、信用卡、汽车和其他消费；列 LTV、地区、期限和风险评级。

### 信用成本与费用模型

- **拨备勾稽**：必须建立 `期初拨备 + provision − net charge-offs + 回收 = 期末拨备`，区分会计拨备、监管资本要求和经济损失。
- **信用成本**：不用当期实际值外推，用跨周期均值加周期位置调整。衰退情景下的信用成本必须参考该行历史峰值和同业峰值。
- **证券组合**：检查 AFS/HTM 未实现损益、久期、对冲和抵押融资能力。**不能因为 HTM 损失不进 OCI 就视作不存在**——压力期被迫出售会立即实现。
- **存款**：看零售/企业、无息/计息、保险内/外、集中度和 deposit beta。存款增长不能只看季末时点，必须用日均或月均。
- **费用**：科技投入、合规成本、薪酬递延和分行网络调整分列。经营杠杆需用收入增速减费用增速验证，而非只看 efficiency ratio。
- **资本桥**：CET1 变化必须拆盈利、RWA 变动、OCI、分红、回购和监管过渡影响。

### 稳态假设边界

- 优质银行可长期维持 ROTCE 高于权益成本，但必须由低成本核心存款、稳定资产质量和费用杠杆支持。
- 若存款成本上升、Stage 2 迁徙恶化、CET1 接近监管底线，不能同时给高增长、低信用成本和高分红。
- 增长只在 `ROTCE > COE` 且资本可支持时创造价值。资本不足时的增长会稀释每股价值。
- 压力测试必须包含：衰退、失业率上行、房价/CRE 下跌、利率急升急降和存款流失情景。

## 6. 估值方法

Scenario analysis可参考的参数
| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 跨周期 ROTCE | | | | |
| 权益成本 COE | | | | |
| 跨周期信用成本率 | | | | |
| 长期 TBV 增速 g | | | | |
| 合理 P/TBV | | | | |
| 情景概率 | | | | |

### 优选

1. **P/TBV 与可持续 ROTCE 交叉**：核心方法。`合理 P/TBV ≈ (ROTCE − g) / (COE − g)`。必须说明用的是跨周期 ROTCE 而非峰值。
2. **反向估值**：由现价倒推市场隐含的长期 ROTCE、信用成本和权益成本，回答"市场已经 price in 了什么"。

### 次选

- **SOTP**：全能银行同时有零售、企业、投行、资管、保险时使用，各分部给不同资本占用和倍数。
- **清算/重估价值**：严重折价或资产质量存疑时，用调整后 TBV（扣除 HTM 未实现损失、拨备缺口和商誉）设下限。
- **并购视角**：检查商誉、每股 TBV 稀释回收期和成本协同兑现记录。

**不使用普通企业 FCF / EV-EBITDA 作为银行主估值**——负债是经营原料，企业价值概念不适用。

### Peer set 规则

选择 5-10 家可比银行，并标注选择理由：

- 业务模式：零售主导、企业主导、全能、投行型、数字银行。
- 资产规模与监管分层：G-SIB、区域银行、社区银行适用不同资本要求。
- 地理与利率环境：所处央行政策周期、存款竞争强度、房地产周期位置。
- 资产质量周期位置：信用成本处于低位、正常化中还是出清中。
- 资本状态：CET1 富余程度与分红回购能力。

剔除项必须说明：若某银行看似同业但资产结构、监管框架或资本要求明显不同，不应强行放入同一 P/TBV 表。

## 7. 护城河与竞争判断

银行护城河的核心是**存款特许权**，不能只写"品牌好"。至少从以下维度打分：

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 存款特许权 | 低成本核心存款占比高，加息周期 deposit beta 显著低于同业 | 存款靠高息揽储，beta 接近或高于同业 |
| 存款分散度 | 户均金额小、保险内占比高、行业分散 | 大额/未保险/单一行业存款集中 |
| 主办行关系 | 企业客户结算、现金管理、贷款捆绑，转换成本高 | 只有单一贷款关系，价格竞争即流失 |
| 风险选择能力 | 跨周期信用成本持续低于同业，且非靠低风险低收益资产 | 高收益资产但周期中损失率跳升 |
| 费用效率 | efficiency ratio 持续优于同业且非靠削减投入 | 低费用率来自科技投入不足 |
| 规模与网络 | 分行/数字渠道形成获客成本优势 | 网络冗余，维护成本高于收益 |
| 资本内生能力 | 盈利可同时支持增长、分红和资本积累 | 增长依赖外部融资或压缩资本缓冲 |

定性护城河必须与财务证据交叉：若声称"优质存款基础"，但无息存款占比持续下降、deposit beta 高于同业，必须解释矛盾。
