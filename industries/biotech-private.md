# Biotech 一级市场行业附录

适用范围：pre-IPO 创新药公司（biologics/小分子/细胞基因治疗/ADC/RNA 等）、平台型 biotech（AI 制药、蛋白设计、递送平台）、诊断与生物工具初创。已商业化药企走 `pharma`（本附录的后期补充）；医疗服务/器械走 `healthcare-services`。

## 1. 使用原则

- Biotech 一级研究的主轴是**科学可信度 × 临床里程碑 × 资金 runway**三线并行：科学站不住，后面全免谈；科学站得住，死于 runway 的公司也一样多。
- **数据质量高于数据数量**：一个设计严谨的随机对照数据点 > 十个单臂小样本"积极信号"。对公司披露的临床数据先做设计审查（对照组、终点选择、样本量、亚组挑选），再看结果。
- **注册库是照妖镜**：所有管线声称回 ClinicalTrials.gov 核对——阶段、入组进度、主要终点是否中途变更（终点变更是重大红旗）、预计读出时间。
- 平台型公司（AI 制药等）的平台价值必须落到**管线证据**：平台产出的分子进入临床几个、进度快不快、合作方（pharma）是否真金白银付费验证。无管线的平台故事按期权处理。
- base rate 纪律：阶段成功率、研发周期、资金消耗都有行业分布（`valuation-private.md` 第 5 节），任何超越 base rate 的假设（"我们的 Ph2 成功率 80%"）必须给结构性理由（如已验证靶点的 fast-follow）。

## 2. 信息来源与核验

- **注册库**：[ClinicalTrials.gov](https://clinicaltrials.gov)（全部试验的设计/状态/终点/时间线，含历史版本比对——终点变更可查）、中国药物临床试验登记平台、EU CTR。
- **监管**：FDA（IND/BTD/Fast Track/ODD 授予可部分公开核对）、获批药数据库（Drugs@FDA）、审评文件（已上市同类药的 FDA 审评报告是竞品分析金矿）。
- **科学文献**：PubMed/期刊原文（数据出处）、会议摘要（ASCO/AACR/ASH/ESMO 的 poster 与口头报告分量不同）、PubPeer（撤稿与质疑记录）。
- **专利**：Google Patents——权利范围、到期时间、发明人与科学创始人的一致性。
- **竞争管线**：同靶点/同适应症的全球管线扫描（注册库+文献+公司管线页交叉），标注各家阶段与数据成熟度。
- **融资信号**：crossover 基金进入（IPO 前信号）、pharma 战投/合作（最硬的第三方科学背书——付了多少首付款是关键，小额合作可能只是期权布局）。
- data room：完整临床数据包、FDA 沟通纪要（pre-IND/EOP2 会议纪要的措辞）、CMC 进度——公开信息覆盖不了的核心，缺失时如实降级。

## 3. 价值驱动树

```text
Biotech 价值 =
  Σ 各管线资产 [
    峰值销售（患者池 × 渗透率 × 定价 × 治疗时长）
    × 累计成功概率（当前阶段 → 获批，base rate 调整）
    × 经济分成比例（自有 vs 已授权的分成结构）
    − 剩余研发与注册成本
  ] 折现
  + 平台期权价值（后续管线产出能力，单列不进 base case）
  − 到下一里程碑的融资缺口（稀释预期）
```

报告中至少回答：

- 核心资产的科学假设是什么？已被什么级别的证据验证（体外/动物/人体早期/概念验证）？
- 到下一个价值拐点（IND/Ph1 读出/Ph2 POC）需要多少钱、多少时间？现金够不够？
- 同靶点全球竞争格局：标的排第几、差异化是什么（疗效/安全性/给药便利性/人群）？
- 若成药，商业化路径：自建销售（烧钱）还是授权（分成）？潜在买家/合作方是谁？
- 关键人依赖：科学创始人/首席医学官离开，项目还能推进吗？

## 4. 核心 KPI 字典

| KPI | 计算/定义 | 研究用途 | 常见陷阱 |
|---|---|---|---|
| 管线阶段分布 | 各资产所处阶段 | 价值与风险地图 | "IND-enabling"可以拖两年 |
| 现金 runway | 现金/月消耗 | 生死线 | 按"到里程碑"算而非按月烧钱平均 |
| 月消耗（burn） | 研发+管理净消耗 | 融资节奏推演 | 临床启动后 burn 跳升 |
| 里程碑时间表 | 各资产关键读出时间 | 催化剂日历 | 入组速度决定一切，查注册库实际进度 |
| 入组进度 | 实际入组/目标 | 时间表可信度 | 入组慢=适应症选择或中心关系问题 |
| 数据质量分 | 设计审查结论 | 声称的含金量 | 单臂/小样本/事后亚组 |
| 合作交易条款 | 首付款/里程碑/分成 | 第三方科学定价 | 总包吹大、首付款很小 |
| 专利到期与范围 | 核心专利寿命 | 商业价值窗口 | 只有方法专利没有物质专利 |
| 同靶点竞争位次 | 全球同类进度排名 | 先发/跟随定位 | 只数直接同分子，忽略替代机制 |
| 团队临床履历 | 推到过 IND/NDA 的人数 | 执行力先验 | 顾问挂名冒充全职 |

必须优先披露的 6 个指标：管线阶段与里程碑时间表、现金 runway（到里程碑口径）、核心资产数据质量审查结论、同靶点竞争位次、合作条款（若有）、团队临床执行履历。

## 5. 管线与平台剖析

- **逐资产建档**：靶点/机制、适应症与患者池、当前阶段、下一读出、竞争位次、成功概率（base rate ± 调整理由）。
- **数据设计审查清单**：对照组有无、随机与盲法、主要终点是否临床认可（替代终点要标注）、样本量、亚组是否事后挑选、脱落率。任何一项不过关，该数据降级为"信号"不作"验证"。
- **平台验证阶梯**（平台型公司按此定位）：纯计算/论文 → 湿实验验证 → 动物 POC → 首个 IND → 临床数据 → pharma 付费合作。阶梯位置决定平台期权的可信度；宣传语言超前于阶梯位置的差距=叙事通胀度。
- **AI 制药特化**：AI 缩短了哪一段（发现≠开发，临床阶段 AI 帮不了多少）、湿实验闭环规模、与传统方法的对照证据；同时读 `ai-native.md` 第 7 章 wrapper 检验（通用模型进步会不会抹平其计算优势）。
- **CGT/ADC 等复杂模态**：CMC（生产工艺）是隐形关卡——工艺放大失败史在该模态的 base rate 不低，data room 查 CMC 进度。

## 6. 估值方法（一级）

按 `valuation-private.md` 执行（rNPV 主法与阶段成功率表在该文件第 5 节），本附录特化：

### 估值假设表（逐核心资产）

| 假设 | Bear | Base | Bull | 依据 |
|---|---:|---:|---:|---|
| 峰值销售 | | | | 患者池×渗透×定价，对照同类真实曲线 |
| 累计成功概率 | | | | base rate ± 调整理由 |
| 上市时间 | | | | 注册库进度推演 |
| 分成/自有比例 | | | | 合作条款 |
| 折现率 | | | | 阶段风险 |

1. **rNPV 加总 + 平台期权单列**：核心资产 rNPV 是 base case；平台与早期管线单列期权价值，不进 base case。
2. **Licensing comps**：同靶点/同阶段的授权交易（首付款+总包）——第三方科学定价的最硬锚；BioPharma Dive/Evaluate 类数据库或公开公告收集。
3. **IPO/M&A comps**：同适应症同阶段的 IPO 发行市值与并购对价；biotech 二级窗口开合剧烈，标注当前窗口状态。
4. **轮次 comps**：crossover 参与的后期轮定价参考性强；早期轮定价噪音大，只作区间。
5. **反向检验**：本轮估值隐含的"成功概率 × 峰值销售"组合——反推出的隐含成功率若显著高于 base rate，写明公司需要什么证据支撑。

### Peer set 规则

- 按模态+适应症+阶段三重匹配；跨适应症的同靶点可作辅助。
- licensing comps 注明交易结构（首付款占比），总包数字单独不可比。

## 7. 护城河与竞争判断

| 维度 | 强证据 | 弱证据/反证 |
|---|---|---|
| 分子/物质专利 | 核心物质专利 + 长寿命 + 宽权利 | 只有用途/方法专利 |
| 数据领先 | 同靶点唯一人体 POC 数据 | 领先 6 个月且后面追兵资金更雄厚 |
| 平台可重复性 | 平台连续产出多个进入临床的分子 | 单一资产公司讲平台故事 |
| 生产工艺（CGT/ADC） | 自有工艺与产能，放大已验证 | 依赖 CDMO 排期，工艺未锁定 |
| 监管路径优势 | ODD/BTD/加速审批资格已获授 | "计划申请"状态 |
| 团队执行记录 | 完整推过 IND→NDA 的团队 | 全学术背景，无注册申报经验 |

## 8. 一级尽调红旗

- 注册库记录与宣传不符（阶段夸大、终点中途变更、入组停滞）
- 数据只在公司 PR 出现，无会议/期刊披露且拒绝提供原始数据
- 关键论文有 PubPeer 质疑/撤稿史且未回应
- 合作交易只有"总包"宣传，首付款极小或未披露
- 现金 runway < 到下一里程碑所需时间，且未主动披露融资计划（隐性 down round 前夜）
- 科学创始人已实质离场（发文/专利活动转移）但仍挂名宣传
- CMC 外包方更换频繁或工艺放大屡次延期
- 同一批投资人/顾问在多个同靶点公司任职（利益冲突与信息墙问题）
