# 团队背景调查手册

一级投资中团队权重远高于二级。本手册定义：查什么、怎么验证、什么算红旗、边界在哪。**产出三件**：核查表、红旗清单、综合评级（高/中/低/无法评估）。

## 1. 合规与伦理边界（先读，硬性）

- **只用公开可获取信息**：LinkedIn、X、GitHub、公司官网、媒体报道、法院公开记录、监管公开处罚、链上公开数据、论文与专利库。
- **不做的事**：不访问需要伪装身份的渠道；不汇编与投资判断无关的私人信息（家庭、健康、私生活）；不对私人个体输出指控性结论——只列可验证事实 + 来源，判断句限于"与投资相关的可信度评估"。
- 敏感发现（诉讼、纠纷、争议离职）：写"存在公开记录 + 来源链接 + 需人工核实"，不下定性结论。
- 单一匿名爆料（X 帖、论坛）标 `[未验证]`，只能触发进一步核查，不能单独作为红旗成立的依据。

## 2. 核查表（正文硬性格式）

对 CEO/CTO 及关键成员逐行：

| 成员/角色 | 声称（履历/学历/成就） | 验证结果 | 来源 | 判定 |
|---|---|---|---|---|
| | | 证实 / 部分证实 / 无法验证 / **矛盾** | | |

验证方法优先级：
1. **交叉一致性**：LinkedIn vs 官网 vs 媒体报道 vs 会议演讲介绍——时间线对不对得上（重叠任职、消失的年份）。
2. **硬记录**：论文（Google Scholar 作者位次）、专利（发明人列表）、GitHub（commit 史是不是本人真实贡献）、监管注册（FINRA BrokerCheck、SEC IAPD、医师执照库）。
3. **前公司验证**：声称的任职公司是否在该时期真实存在该职位/项目；"曾任 X 公司核心成员"要看是 founding team 还是普通雇员。
4. **成就归属**：声称"做出过 Y 产品/协议"——查当时的公告、代码贡献、团队页面存档（Wayback Machine 是利器）。

## 3. 分赛道附加核查

### Crypto
- **匿名分级**：实名（KYC 级公开）/ 半匿名（业内知道真人）/ 全匿名。全匿名不是自动否决，但（a）资金托管与多签结构要求更高（b）评级上限"中"。
- **链上历史**：团队/deployer 地址过往部署的项目 → 那些项目的结局（rug、放弃、正常）；金库地址行为（是否有异常转出到 CEX）。
- **上一周期履历**：声称"经历过上一轮牛熊"的，查当时项目的实际结局与用户资金结果。
- **监管记录**：SEC/CFTC/DOJ 公开 action 检索姓名与项目名。

### AI
- **论文真实性**：作者位次（一作/通讯 vs 挂名）、引用量、是否真的出自声称的实验室。
- **大厂履历成色**：L 级别/职级线索、在核心团队还是外围（媒体报道与领英同事网络佐证）。
- **GitHub 贡献**：明星 repo 的 commit 是否集中在本人。

### Biotech
- **科学创始人**：h-index、关键论文是否被重复验证（有无撤稿/质疑，查 PubPeer）、专利发明人 vs 论文作者一致性。
- **临床团队**：有没有真的把药推到过 IND/NDA 的人（查 FDA 记录与前公司管线时间线）。
- **顾问委员会成色**：大牛顾问是实质参与（持股、共同发文）还是挂名。

## 4. 红旗清单（逐条核查，命中列证据）

**诚信类（否决级候选）**
- 履历造假或关键成就归属不实（核查表出现"矛盾"）
- 过往项目 rug/暴雷且未向投资人披露
- 公开的欺诈/证券违规记录
- 声称的合作/客户被对方否认

**结构类（重度扣分）**
- 团队 token/股权份额异常高（对照 `valuation-private.md` 红旗阈值）或 vesting 异常短
- 核心成员兼职做多个项目（GitHub/领英活动佐证）
- 一年内核心成员连续出走（领英离职时间线）
- 关联方交易迹象（做市商/审计方/大客户与团队关联）

**能力类（校准预期）**
- 履历全部来自失败项目且无归因反思
- 技术声称与团队构成不匹配（声称自研模型但无研究人员）
- 顾问名单豪华但无实质参与证据

**加分项（如实列，避免只找负面）**
- 连续成功创业者（有真实退出记录）
- 核心技术的真实一作/主要贡献者
- 完整经历上一周期且项目善终
- 早期员工/用户自发追随（前同事跟随入伙）

## 5. 综合评级规则

| 评级 | 条件 |
|---|---|
| **高** | 核查表全部证实/部分证实，无诚信红旗，有 ≥1 加分项 |
| **中** | 无诚信红旗，但存在结构/能力类红旗或较多"无法验证" |
| **低** | 命中结构类红旗多项，或诚信类存在未澄清疑点 |
| **无法评估** | 全匿名且链上历史不可考，或公开信息不足以核查 |

诚信类红旗**证据确凿**时不给评级，直接在报告结论建议 Pass（否决级）。评级写入报告头部结论框与数据可得性声明并列。
