# 一级市场估值方法手册

一级估值的诚实答案往往是"一个区间 + 一组隐含假设"，而不是一个数。本手册的纪律：**至少两法交叉、全部脚本计算、每个结论绑定退出路径、crypto 一律 FDV 口径**。

## 1. 方法选择矩阵（阶段 × 赛道）

| 阶段 \ 赛道 | Crypto | AI-native | Biotech | 传统 |
|---|---|---|---|---|
| Pre-seed/Seed（pre-product） | 轮次 comps + token economics 结构检验 | 轮次 comps + 团队/算力资产 | rNPV 太早 → 里程碑倒推法 | 轮次 comps |
| A/B（有产品有数据） | 轮次 comps + 二级锚倍数折价 + 协议收入倍数 | 轮次 comps + ARR 倍数 vs 二级软件折价 | 逐资产 rNPV + licensing comps | 收入倍数 comps + 二级锚折价 |
| Growth/Pre-listing | 二级锚倍数为主 + unlock 调整 | 二级锚倍数为主（ARR/毛利倍数） | rNPV + IPO comps | 二级锚倍数为主 |

**至少两种方法**；方法间区间不重叠时必须解释分歧来源（通常是"公司口径 KPI 可信度"或"退出假设不同"）。

## 2. 一级轮次 comps（`scripts/comps_builder.py`）

**同赛道 + 同阶段 + 同周期**三重匹配，缺一必须调整：

- **周期调整**：2021H2 与 2023 的同赛道同阶段估值可差 3–10 倍。comps 时间窗默认取近 18 个月；引用更早轮次必须标注周期位置并降权（不进中位数，只作参照）。
- **阶段对齐**：用"数据成熟度"对齐而非轮次名——A 轮标签通胀严重，看 ARR/TVL/用户量级是否同级。
- **口径还原**：post-money vs pre-money；token deal 的估值 = FDV（equity+token warrant 的按条款拆分）；含大额 credit/非现金的融资额要剔除。
- **结构调整**：高 liquidation preference、ratchet、超额参与权会让 headline 估值虚高 20–50%；条款不可得时标注"headline 口径"。
- 输出：comps 表（含每家的关键 metric 与倍数）→ 中位数/四分位 → 标的隐含估值区间 → **本轮报价所处分位**。

## 3. 二级锚折价法（与 industry mapping 第三章联动）

从产业地图中该层的二级锚（上市公司/流通 token）取倍数，向下折价：

| 折价项 | 典型区间 | 说明 |
|---|---|---|
| 流动性折价 | 20–35% | 无退出通道、锁定期；DLOM 研究的经验区间 |
| 阶段/存活风险折价 | 0–40% | 按数据成熟度：growth 期 0–15%，A 轮 25–40% |
| 信息不对称折价 | 5–15% | 数据可得性等级 C/D 时取高档 |
| 规模流动性溢价（反向） | −20–0% | 小体量高增长可部分抵消，需证据 |

**纪律**：折价叠加不是简单相加（用乘法：(1−d1)(1−d2)…）；总折价超过 60% 时说明二级锚选取有问题，回到轮次 comps。折价参数是**经验区间不是定律**，每次使用写明取值理由。crypto post-TGE 项目对流通同类协议比较时流动性折价降为 0–10%（token 本身可流动），但要加 **unlock 悬顶折价**（见第 4 节）。

## 4. Token economics 检验（`scripts/token_economics.py`，crypto 必做）

估值判断之前先做结构检验，四问：

1. **FDV 纪律**：一切倍数用 FDV 计算，同时披露流通市值与 float%。低 float + 高 FDV = 价格发现失真，二级锚对比时显式标注。
2. **供给压力**：未来 12/24 个月新增供给占当前流通的比例；>50%/年 为重度悬顶，估值结论必须假设"吸收这些供给需要多少新增需求"。
3. **成本结构**：各轮投资人成本（FDV 口径）与当前/本轮价格的 MOIC——前轮投资人浮盈 >10x 且临近解锁 = 结构性卖压。
4. **价值捕获**：token 拿到协议现金流了吗（fee switch/burn/分红）？没有的话协议收入倍数只能作参照，估值本质是"治理权+预期"，写明。

**红旗阈值**（脚本自动标记）：内部人（团队+投资人）份额 >40%；团队 vesting <24 个月；TGE float <5%；12 个月供给增长 >100%。

## 5. rNPV（biotech 主法）

- 逐资产：`rNPV = Σ [峰值销售路径 × 成功概率(按阶段 base rate) × 利润率 − 剩余研发成本] 折现`。
- 阶段成功率 base rate（行业长期均值，报告中标注为经验值并按适应症调整）：

| 阶段转换 | 全适应症均值 | 备注 |
|---|---|---|
| Ph1 → Ph2 | ~52% | |
| Ph2 → Ph3 | ~29% | 最大死亡谷 |
| Ph3 → 申报 | ~58% | |
| 申报 → 获批 | ~90% | |
| Ph1 → 获批（累计） | ~8–10% | 肿瘤更低，罕见病更高 |

- 平台型公司：管线 rNPV 加总 + 平台期权价值单列（不进 base case）。
- 交叉验证：同适应症同阶段的 **licensing deal comps**（首付款+里程碑总包）与 IPO/M&A comps。
- 关键输入（峰值销售、渗透率、定价）对照已上市同类药真实曲线，不用公司 deck 的 TAM。

## 6. 反向估值检验（Step 4.5 必做）

回答"**本轮估值隐含什么**"：

- 隐含倍数 = 本轮估值 / 当前关键 metric → 与二级锚中位数的差距倍数 → "需要 metric 涨 N 倍才能对齐二级中位数"。
- 隐含终局：按下轮/退出目标回报倒推（VC 定价恒等式：本轮估值 ≈ 退出估值 × 存活概率 / 目标 MOIC）；写出"这个价格隐含它成为该赛道 Top N"之类的可评判命题。
- 对照 base rate：该赛道上一周期到达这个终局的项目有几个。

## 7. 退出路径与回报（每个估值结论必须落到这里）

| 退出路径 | 适用 | 关键变量 |
|---|---|---|
| 下轮融资加价 | 早期主要"退出"形式（账面） | 下轮时间、里程碑、市场周期 |
| TGE/token 上线 | crypto | 上线 FDV comps、我们的解锁条款、上线后流动性 |
| IPO | growth/biotech | 二级锚当前倍数、发行窗口 |
| M&A | 全部 | 买家名单（industry mapping 里谁在收购）、历史并购倍数 |

输出：base/bull/bear 三情景 × 退出估值 × 时间 → **隐含 IRR 与 MOIC**（脚本计算）。情景概率受当前证据强度约束，不许拍脑袋 25/50/25。

## 8. 输出规范（估值章）

1. 估值假设表（每法一张，含来源与依据）
2. Comps 表 + 中位数/分位（一级、二级分开）
3. 文本版估值对比图（football field，`output-format.md` 第 5 节）
4. crypto：unlock 压力表 + 红旗清单
5. 反向检验：本轮报价隐含假设 1–3 条（可证伪句式）
6. 退出情景表 + 隐含 IRR/MOIC
7. 全部计算出自 `scripts/`，假设 JSON 留档；正文标注"计算见附录摘要"
